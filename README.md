# Quesos Ocosingo

Sistema web orientado a la gestión administrativa de un negocio dedicado a la venta de quesos y productos artesanales.

## Descripción

Quesos Ocosingo fue desarrollado para centralizar procesos que anteriormente se realizaban de forma manual, facilitando la administración de la información y reduciendo errores en las operaciones del negocio.

El sistema permite gestionar información relacionada con productos, clientes, empleados y proveedores, además de contar con autenticación de usuarios y generación de reportes en formato PDF.

## Objetivo

Mejorar la organización y consulta de la información del negocio mediante una aplicación web que permita realizar operaciones administrativas de forma más ordenada y accesible.

## Funcionalidades principales

- Inicio de sesión.
- Gestión de productos.
- Gestión de clientes.
- Gestión de empleados.
- Gestión de proveedores.
- Consulta de registros.
- Registro de información.
- Modificación de datos existentes.
- Eliminación de registros.
- Generación de reportes en PDF.
